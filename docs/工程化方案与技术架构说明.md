## 1. 项目概述

### 1.1 产品定位

AI Workspace 是一个面向「构建与管理 AI 智能体」的现代化 SaaS 工作台：用户可以创建并配置 Agent，为其装配 Skills（技能）、Tools（工具）、Memory（记忆）与 Rules（规则），把工作组织进 Projects（项目），并通过 Dashboard 实时观察运行状况。它对应真实产品中"Agent 运行时 + 能力市场 + 记忆系统 + 治理规则"的统一控制面。

### 1.2 本阶段范围（Phase 1 整体）

- ✅ 高质量前端 Demo：8 个核心模块 + 应用壳（导航/命令面板/主题）
- ✅ Mock 数据层 + 异步模拟，完整呈现交互与状态
- ❌ 暂不接真实后端、数据库、AI 服务、认证、计费
- ❌ 暂不做浅色主题（token 体系预留，见 §5.3）

### 1.3 核心原则（优先级排序）

1. **工程质量**：类型安全、组件复用、无重复代码、可验证构建
2. **UI 品质**：专业、简洁、层次清晰、卡片化、高信息密度、细腻微交互
3. **长期可维护性**：模块边界清晰、数据层可替换、规范可执行

### 1.4 成功标准

- 8 模块全部可达且交互完整（增删改、筛选、搜索、状态反馈）
- 共享组件复用率 > 60%（无同类重复实现）
- `npm run lint` / `tsc --noEmit` / `npm run build` 零错误
- 桌面优先 + 移动端可用的响应式体验

### 2.1 目标用户与核心任务

### 4.3 Agent 详情 `/agents/[id]`

### 4.4 Agent 新建 `/agents/new`

分步表单：基本信息 → 模型与参数 → 装配能力 → 记忆与规则 → 预览提交（步骤指示器 + 校验 + 提交成功 toast 并跳详情）。

### 4.8 Tools `/tools`

## 5. UI/UX 设计规范

### 5.1 设计原则

专业（克制的装饰、清晰层级）、简洁（信息优先、无冗余元素）、层次（表面分层 + 边框 + 阴影表达深度）、卡片化（内容以卡片承载）、高信息密度（紧凑排布、tabular 数字）、微交互（反馈即时而克制）。

### 5.2 视觉风格：现代高级深色 AI SaaS

- 深色近黑冷调背景，三层表面递进；细边框（白色低透明度）代替硬阴影
- 品牌色：紫罗兰 → 靛蓝渐变（科技感），用于主 CTA、选中态、品牌元素
- 语义色克制使用（状态点/徽标），大面积底色禁用
- 局部径向渐变光晕（品牌色 6–10% 透明度）点缀卡片与页头，增强"AI 氛围"
- 大圆角（12–16px）卡片 + 中等圆角（8px）控件；字号以 13–14px 为主，标题 16–20px

### 5.3 设计 Token（CSS 变量，`globals.css` 定义）

### 5.4 排版与图标

- 字体：Geist Sans（正文/标题）、Geist Mono（数字、代码、manifest）
- 字号阶梯：12 / 13 / 14 / 16 / 20 / 24 / 30 / 36；字重 400/500/600/700

## 6. 组件体系

```
Page 层（app 路由页面，组合区块）
  └─ Feature 层（components/<module>/，模块私有组件）
      └─ Shared 层（components/shared/，跨模块共享）
          └─ UI 层（components/ui/，shadcn 基座）
```

依赖只允许自上而下；Shared 不依赖 Feature；UI 不依赖业务。

## 8. 技术架构

### 8.1 选型理由

| 选型 | 理由 |
| --- | --- |
| Next.js 15 App Router | 路由即文件结构；RSC 承载静态骨架；官方生态 |
| React 19 + TS strict | 类型安全，组件模型成熟 |
| Tailwind CSS | 原子样式 + token 化，暗色主题友好 |
| shadcn/ui | 可定制原语（Radix + Tailwind），非黑盒 UI 库 |
| Lucide | 高质量线性图标，按需引入 |
| Framer Motion | 声明式动画、spring、入场/离场编排，与 React 深度集成 |
| Zustand | 轻量、无样板、中间件（persist） |

### 8.2 渲染策略

- 静态路由骨架（标题、导航配置）走 RSC；交互区块为 Client Component（`"use client"`）
- 列表/表单等数据展示通过 hooks 调用 store 初始化，异步 mock 呈现加载态
- 全站客户端渲染为主（SaaS 工作台特性），SSG 输出壳以利首屏

### 8.3 状态管理（Zustand）

| Store | 状态 | 持久化 |
| --- | --- | --- |
| useUiStore | 侧边栏折叠、移动端抽屉、命令面板开关 | ✅ 部分（折叠态） |
| useAgentsStore | agents 列表、筛选、CRUD、运行动作 | ❌（种子数据） |
| useSkillsStore / useMemoryStore / useRulesStore / useToolsStore / useProjectsStore / useRunsStore | 各自领域数据 + 操作 | ❌ |

- 选择器化使用：`useAgentsStore(s => s.agents)`，避免全量订阅
- 领域动作调用 `services/*`（模拟 async），结果写入 store

### 8.4 数据层（服务抽象）

- `services/*` 导出**带类型契约**的 async 函数（`Promise<T>`）
- Mock 实现：`lib/mock-data` 种子 + `simulateLatency(150–400ms)`，支持模拟失败（如删除确认）
- 未来替换真实 API：仅改 services 内部实现，组件与 store 不动

### 8.5 样式方案

- Tailwind + CSS 变量（§5.3）；shadcn 主题映射为暗色
- 工具类统一语义：`bg-surface-1`、`text-2`、`border-default` 等（tailwind.config 扩展）

```
Agent ◄──装配── Skills / Tools（多对多，agent 持有 ID 数组）
Agent ◄──关联── Rules（作用域可为 agent）
Agent ◄──产生── Run（运行记录）
Project ◄──包含── Agents
MemoryEntry 独立条目（scope: session/workspace/global）
ActivityItem 由各实体事件生成（时间线）
```

### 9.2 核心类型（摘要）

```ts
interface Agent {
  id: string; name: string; description: string;
  status: AgentStatus;                 // active | draft | paused | archived
  model: string; temperature: number; instruction: string; tags: string[];
  skills: string[]; tools: string[]; rules: string[]; projectIds: string[];
  memory: { enabled: boolean; scope: MemoryScope };
  stats: { runs: number; successRate: number; avgLatencyMs: number; tokensUsed: number };
  createdAt: string; updatedAt: string;
}

interface Skill { id; name; description; version; category: SkillCategory;
  author; usageCount; status: 'installed' | 'available' | 'deprecated'; manifest: string; }
interface MemoryEntry { id; content; type: MemoryType; source: MemorySource;
  scope: MemoryScope; tags: string[]; confidence: number;
  createdAt; lastAccessedAt; }
interface Rule { id; name; description; enabled; priority: 1|2|3|4|5;
  scope: 'global' | 'agent' | 'project'; effect: 'allow' | 'deny' | 'transform';
  condition: { field: string; op: 'eq' | 'neq' | 'contains' | 'gt' | 'lt'; value: string };
  triggerCount: number; lastTriggeredAt?: string; agentIds: string[]; }
interface Tool { id; name; description; category: ToolCategory;
  status: 'connected' | 'available' | 'error'; auth: 'oauth' | 'api_key' | 'none';
  usageCount; avgLatencyMs; schemaFields: { name; type; required }[]; enabled: boolean; }
interface Project { id; name; description; status: ProjectStatus; agentIds: string[];
  tags: string[]; progress: number; createdAt; updatedAt; }
interface Run { id; agentId; status: RunStatus; startedAt; durationMs;
  tokensUsed; cost; inputPreview; outputPreview; error?: string; }
interface ActivityItem { id; type: 'run' | 'agent_created' | 'memory_added' | 'rule_updated' | 'project' | 'system';
  message: string; timestamp: string; }
```

枚举集中在 `types/enums.ts`；API 响应统一 `{ data: T; error?: { code; message } }`。

## 11. 动画规范（Framer Motion）

| 场景 | 变体 | 参数 |
| --- | --- | --- |
| 页面切换 | fade + y(8→0) | 250ms `ease-out` |
| 列表入场 | stagger（子项 fadeUp） | 间隔 40ms |
| 指标数字 | useCountUp（tween/spring） | 400ms |
| 卡片 hover | y: -2 + 边框/阴影 | 150ms |
| 按钮按压 | scale 0.97 | 100ms |
| 命令面板 | 顶部 scale/fade 进入 + sheet 式 | 200ms |
| 骨架屏 | shimmer 循环 | 1.4s |
| 开关/滑块 | layout spring | stiffness 400 / damping 30 |

- 所有动效通过 `useReducedMotion()` 降级为瞬时切换
- 动画仅用于「反馈与层级」，不做持续装饰动效
